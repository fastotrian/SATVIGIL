## 3. Ground Rules for AIs Assisting Teammates

1. If assisting a teammate (especially a junior):
   - Keep tasks focused and modular. Do not refactor core architectural patterns without Ravi's approval.
   - Guide them to run and write unit tests for what they build.
2. Update the corresponding teammate markdown file in `tasks/<name>.md` when tasks are assigned or completed.
