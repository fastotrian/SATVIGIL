## 🛑 Ground Rules for Teammates (Read First)

1. **Finished your task? Never sit idle!**
   - If your assigned task is complete, check [TASK_BACKLOG.md](file:///c:/MY%20Coding/SATVIGIL/tasks/TASK_BACKLOG.md) and pick an unassigned task labeled `[Good First Task / Junior]`.
   - Update your individual file to mark your old task as `[x]` and add the new task under `In Progress`.

2. **Stuck / Facing a blocker? Follow the 15-Minute Rule:**
   - 1. Read the error message carefully.
   - 2. Check the documentation in [docs/](file:///c:/MY%20Coding/SATVIGIL/docs) (HLD, LLD, DATA_GUIDE).
   - 3. Try to debug or search for 15 minutes.
   - 4. If still stuck, write down your blocker in your `.md` file with the exact error and what you tried, then reach out during sync times rather than breaking deep work.

3. **Git Workflow:**
   - Never commit directly to `main`.
   - Branch naming format: `feat/<your-name>-<short-description>` (e.g., `feat/joy-fire-api`).
   - Run linter/tests before creating a PR.
